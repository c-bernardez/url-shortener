# URL Shortener

A REST API for shortening long links, built with Java and Spring Boot. Given a long URL, it returns a short alias that redirects to the original destination.

## Project status

The latest version is on the `v2` branch. The service is working and ready to use. I'm now starting development on QR code generation for the short links.

## Features

- Shortens a URL and returns a short alias.
- Supports custom aliases.
- Redirects from the alias to the original URL.
- Links expire after a configurable amount of time.
- Tracks how many times each link has been used.

## Tech stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL

## How it works

1. Each stored URL gets a numeric ID generated by a database sequence.
2. That number is converted to base 62 (digits, uppercase and lowercase letters) to produce a short, unique alias.
3. If a custom alias is requested, the service checks that it isn't already taken before saving it.
4. When a user visits the alias, the service looks up the original URL, checks that it hasn't expired, increments the click counter, and redirects.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | /shorten | Takes a JSON body with "url" (required) and "customAlias" (optional). Returns the short alias. |
| GET | /{alias} | Redirects (HTTP 302) to the original URL. |

## Error responses

| Code | When it happens |
|------|-----------------|
| 400 | The URL is missing or blank. |
| 404 | The alias does not exist. |
| 409 | The custom alias is already in use. |
| 410 | The link has expired. |

## Configuration

* Link lifetime is set in the application properties file with the key `url.expiration.minutes`.
* Database credentials are set in the application properties, but read from the environment variables `DB_USERNAME` and `DB_PASSWORD`.

## Running it locally

1. Clone the repository and check out the `v2` branch.
2. Start a PostgreSQL instance on localhost:5432 with a database named `urlshortener`.
3. Set the environment variables `DB_USERNAME` and `DB_PASSWORD` with your database credentials.
4. Run the application with `./mvnw spring-boot:run`, or from your IDE.
5The API will be available at `http://localhost:8080`.
